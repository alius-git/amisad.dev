# SCENARIO-008 sequence — Zero-Knowledge Dispute Mediation and Settlement Adjustment

> One sentence: a delivery dispute resolves on metadata plus one minimal, time-boxed, consented disclosure, the refund lands as compensating entries referencing the case — and the buyer stays anonymous throughout.

See [../design.md](../design.md#9-diagrams) · [SCENARIO-008](../scenarios.md#scenario-008-zero-knowledge-dispute-mediation-and-settlement-adjustment).

```mermaid
sequenceDiagram
    actor Maya
    participant BuyerApp as Buyer app
    participant PlatformSvc as platform-svc (support desk)
    actor Sam
    participant SellerSvc as seller-svc
    actor Elena
    participant LedgerSvc as ledger-svc
    actor Priya

    Note over Maya,Priya: Seeded - a settled order (SCENARIO-001 style) whose delivery confirmation conflicts with reality
    Maya->>BuyerApp: Report non-delivery
    BuyerApp->>PlatformSvc: Case opens - operational metadata only, no identity
    PlatformSvc->>Sam: Case in support queue
    Sam->>PlatformSvc: Review - carrier confirmation conflicts with the report
    alt metadata cannot resolve the case
        Sam->>PlatformSvc: Request consented disclosure - minimal scope, time-boxed
        PlatformSvc->>LedgerSvc: Request recorded in consent ledger
        PlatformSvc-->>BuyerApp: Disclosure request presented to the data owner
        Maya->>BuyerApp: Grant
        BuyerApp->>LedgerSvc: Grant recorded
        LedgerSvc-->>Sam: Exactly the granted artifact, read-only - identity still withheld
    end
    Sam->>PlatformSvc: Evidence supports the buyer - propose refund adjustment
    PlatformSvc->>SellerSvc: Adjustment proposal to the seller
    Elena->>SellerSvc: Accept
    SellerSvc->>LedgerSvc: Compensating entries posted, referencing the case
    LedgerSvc-->>BuyerApp: Adjustment visible to both parties
    Sam->>PlatformSvc: Resolution recorded, case closed
    PlatformSvc->>Priya: Recurring-pattern note to the operations queue
    Note over LedgerSvc: Disclosure grant expires - the access path is gone
    Note over Maya,Priya: Yuruna asserts - case record identity-free end to end, grant history reads request-grant-delivery-expiry with scope never exceeded, adjustment exists only as case-referencing compensating entries, post-expiry access fails
```
